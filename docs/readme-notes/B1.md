# B1 handoff

- Task ID / branch / commit: B1 / `akshat-branch`
- Implemented behavior:
  - Implemented standalone backend server in `src/netbalance/backend.py` supporting `python -m netbalance.backend`.
  - Integrated with A1 shared protocol helpers in `src/netbalance/protocol.py`: `ProtocolError`, `encode_message`, `read_message`, `validate_work`, `validate_health`, and `error_response`.
  - Added CLI flag support for `--id`, `--host`, `--port`, `--service-ms`, and `--capacity`.
  - Protocol & framing: Strict newline-delimited UTF-8 JSON framing, 65,536-byte maximum frame limit (`FRAME_TOO_LARGE`), 2.0-second client read deadline (`CLIENT_READ_TIMEOUT`), single request/response lifecycle per TCP connection.
  - Strict input validation: `work` requests enforce `id` (nonempty string $\le 64$ chars), `op == "work"`, `work_units` (integer $1..10$, booleans rejected), `payload` (string $\le 1024$ UTF-8 bytes). Health requests enforce `id` and `op == "health"`.
  - Concurrency & non-blocking health: Work processing is bounded by `capacity` via an `asyncio.Semaphore`. Simulated delay equals `(service_ms * work_units) / 1000.0`. Health probes completely bypass work capacity slots and remain responsive ($< 100\text{ ms}$) even when work capacity is fully saturated.
  - Disconnect & cleanup resilience: Handles abrupt client disconnects (`ConnectionResetError`, `ConnectionAbortedError`, `BrokenPipeError`, EOF) safely without crashing the listener. Server `stop()` cancels and waits for in-flight tasks, closes all active sockets, and frees the listening port for immediate reuse.
  - Payload privacy in logs: Logs request ID, backend ID, operation, status, and ISO timestamps without logging arbitrary full payloads.
  - Validation bounds: Validates positive integer capacity ($> 0$, no booleans/floats) and finite, nonnegative service duration ($\ge 0.0$, finite numbers).

- CLI Flags:
  | Flag | Type | Default | Description |
  | --- | --- | --- | --- |
  | `--id` | string | *Required* | Unique backend identifier (e.g. `s1`, `s2`, `s3`) |
  | `--port` | int | *Required* | TCP port to listen on ($0..65535$, where $0$ selects an ephemeral port) |
  | `--host` | string | `127.0.0.1` | Host address to bind to |
  | `--service-ms` | float | `50.0` | Base service time in milliseconds ($\ge 0.0$, finite) |
  | `--capacity` | int | `4` | Maximum concurrent active work requests ($> 0$) |

