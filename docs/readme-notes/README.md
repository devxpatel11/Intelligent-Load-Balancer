# Task handoff notes

Each task updates only its matching file. `C0.md` records the shared foundation. Member B never edits the root README directly; Member A integrates both task notes after the day's reviewed merges.

Every note records the task ID, branch/commit, implemented behavior, changed files/contracts, exact commands and actual results, expected versus actual acceptance criteria, raw evidence paths, known limitations/blockers, next-task readiness, and README facts. Planned behavior must remain labelled as planned.
